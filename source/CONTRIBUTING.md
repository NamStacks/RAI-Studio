# Contributing to RAI-Studio

RAI-Studio is an independent fork of the open source RStudio project. It is not made, endorsed or supported by Posit Software, PBC.

Report problems and ask questions in the issues of https://github.com/NamStacks/RAI-Studio/issues. Include the RAI-Studio version and commit shown in Help > About, your macOS version, and the steps that reproduce the problem.

Pull requests are welcome. Keep each one small and say what it changes and why. By sending a pull request you agree that your contribution is licensed under the GNU Affero General Public License version 3, the license of this project.

A problem that also exists in upstream RStudio belongs in https://github.com/rstudio/rstudio/issues.
