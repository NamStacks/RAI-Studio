These scripts built the RAI-Studio 0.1.62 Beta disk image. They compile the native programs, the GWT client and the Electron bundles from this source, patch those pieces, the assistant bridge and the changed R and resource files into a copy of the previous signed release app, then sign and notarize the result. They assume the layout of the build machine: a staging folder (STAGE) that holds the source tree, one native build tree per architecture, the dependency folders and the previous signed release app. Read each script before you run it and adjust the paths. Run them in numeric order: 20-native.sh and 30-gwt.sh, then 40-electron.sh, 50-assemble.sh and 60-release.sh. COMMIT must name the source commit id the binaries report in About. Ninja runs the GWT step through whatever ant the generated build files name; the scripts pass the Apache Ant path explicitly. The stock route that needs no earlier app is package/osx/make-package, described in RAI-STUDIO-RELEASE.md.
